# CARY (كاري) - سوق الشفافية والثقة لسيارات صعيد مصر 🚗✨

منصة متكاملة لبيع وشراء وتصفح السيارات المستعملة والجديدة في محافظات صعيد مصر بكل شفافية وسهولة، مبنية بأحدث تقنيات **Flutter & Dart** وتدعم العمل كتطبيق موبايل (Android / iOS) وموقع ويب متكامل (**Web Application**).

---

## 🚀 المميزات الرئيسية
- 🌐 **دعم كامل للويب والموبايل (Cross-Platform)** مع تصميم متجاوب (Responsive Design) واتجاه كامل من اليمين لليسار (RTL).
- 🔍 **تصفح وفلترة ذكية**: فلترة حسب الماركة، الموديل، المحافظة، السعر، وسنة الصنع.
- 📸 **إضافة الإعلانات**: رفع صور متعددة للسيارة مع معالجة وتحسين الصور للويب والموبايل.
- 💬 **تواصل فوري**: إمكانية التواصل السريع مع البائع أو إدارة المنصة عبر واتساب والاتصال الهاتفي.
- 🔔 **نظام إشعارات**: متابعة حالة الإعلانات والعروض والحجوزات.
- ⚡ **أداء فائق**: تشغيل سلس يدعم حتى 120Hz، وتحسين أحجام الصور والتخزين المؤقت.

---

## 🛠️ متطلبات التشغيل
- Flutter SDK (نسخة 3.22+ أو أحدث)
- Dart SDK (نسخة 3.3+ أو أحدث)
- Google Chrome لتشغيل الويب محلياً

---

## 💻 التشغيل المحلي (Local Development)

### 1. تثبيت الحزم:
```bash
flutter pub get
```

### 2. إعداد المتغيرات البيئية:
قم بنسخ ملف `env.example.json` إلى `env.json` وضع بيانات الـ API والمفاتيح الخاصة بك:
```bash
cp env.example.json env.json
```

### 3. تشغيل الموقع على المتصفح:
```bash
flutter run -d chrome
```

### 4. تشغيل التطبيق على الموبايل:
```bash
flutter run
```

---

## 📦 بناء نسخة الويب للإنتاج (Production Web Build)
لبناء موقع الويب كاملاً لرفعه على أي استضافة (GitHub Pages, Cloudflare Pages, Firebase Hosting, Nginx):

```bash
flutter build web --release
```
الملفات الناتجة ستكون جاهزة في المجلد: `build/web/`

---

## 🌐 النشر التلقائي عبر GitHub Pages
تم إعداد سير عمل آلي (**GitHub Actions**) في المسار:
`.github/workflows/deploy_web.yml`

بمجرد عمل `push` لفرع `main`، سيقوم GitHub ببناء الموقع ونشره تلقائياً على **GitHub Pages**.
> **ملاحظة**: لتفعيل الرابط من GitHub:
> 1. ادخل على مستودع المشروع (Repository Settings).
> 2. اذهب إلى **Pages** من القائمة الجانبية.
> 3. اختر المصدر: **GitHub Actions**.
